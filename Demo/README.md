# FlipStack Demo (receipt UI, build 12)

The receipt-style menu-bar app currently installed on this Mac
(`/Applications/FlipStack.app`, v1.0.1 / build 12). Standalone SwiftPM package
depending on the root FlipStackCore (`path: ".."`).

Build: `swift build -c release` in this folder. Tests: `swift test` (16).
The main app remains the repo root; the previous full version is in `Advanced/`.
